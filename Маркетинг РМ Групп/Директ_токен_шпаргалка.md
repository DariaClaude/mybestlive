# Шпаргалка: токен Яндекс Директа для аудита

Чтобы Клод проанализировал кампании, ему нужен свежий OAuth-токен (живёт ~1 год, потом протухает).
client_id приложения **постоянный**, поэтому ссылка ниже всегда одна и та же.

## Шаг 1. Получить токен — перейти по ссылке

**https://oauth.yandex.ru/authorize?response_type=token&client_id=be151a742b8b4462b30bca8aa223e3fa**

→ войти под аккаунтом `sorockanova-o` → нажать «Войти / Разрешить».

## Шаг 2. Скопировать токен из адресной строки

После входа браузер откроет адрес вида:

```
https://...#access_token=y0_AgAAAAB...&token_type=bearer&expires_in=31536000
```

Скопировать строку **между `access_token=` и `&token_type`** — она начинается с `y0_`.

## Шаг 3. Прислать токен Клоду

Вставить токен в чат и написать: «проверь Директ» (или вызвать скилл **/direct-audit**).
Дальше Клод сам подключится и выдаст аудит.

---

### Постоянные данные аккаунта

| Параметр | Значение |
|---|---|
| client_id приложения | `be151a742b8b4462b30bca8aa223e3fa` |
| Логин Директа | `sorockanova-o` |
| Счётчик Метрики | `99547216` |
| Сайт | rm-info.ru |

### Если токен не работает
- Ошибка «Недействительный OAuth-токен» → получить заново (Шаг 1).
- Работает в Метрике, но не в Директе → у приложения нет права «Яндекс.Директ API».
  Включить на https://oauth.yandex.ru/client/be151a742b8b4462b30bca8aa223e3fa

> ⚠️ Кампании нового типа («Продвижение Telegram-канала») в обычном списке API не видны —
> их статистика берётся только через раздел отчётов. Клод это учитывает.
