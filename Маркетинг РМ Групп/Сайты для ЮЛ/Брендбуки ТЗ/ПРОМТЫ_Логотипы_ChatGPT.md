# Промты для ChatGPT — генерация логотипов 11 юрлиц РМ Групп

**Как использовать:**
- Копируй промт целиком → вставляй в ChatGPT (GPT-4o с генерацией изображений)
- Если вариант понравился частично — напиши: *"Keep variant 2, change the other 4 — try bolder typography / more minimal / add icon element"*
- Для уточнений добавляй: *"Make it more premium / more industrial / lighter / darker"*
- Каждый промт запускай 2–3 раза для разнообразия результатов
