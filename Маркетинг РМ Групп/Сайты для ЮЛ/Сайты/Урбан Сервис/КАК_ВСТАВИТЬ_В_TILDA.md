## Пошаговая инструкция

### Шаг 1 — Базовые стили (один раз)
1. Tilda → Настройки сайта → Ещё → **HTML-код в `<head>`**
2. Скопировать всё содержимое файла `00_базовые-стили.html` и вставить

### Шаг 2 — Каждый блок (01–08)
1. Добавить новый блок на страницу → выбрать **Zero Block**
2. В редакторе Zero Block есть три вкладки: **HTML / CSS / JS**
3. В каждом файле найти секции:
   - `<!-- ═══ CSS ═══ -->` → содержимое `<style>...</style>` вставить в **CSS**
   - `<!-- ═══ HTML ═══ -->` → HTML-код вставить в **HTML**
   - `<!-- ═══ JS ═══ -->` → содержимое `<script>...</script>` вставить в **JS**

### Шаг 3 — Модальная форма
- Файл `08_модальная-форма.html` вставляется **один раз** в любой Zero Block (удобно в конце страницы)
- Форма автоматически перехватывает клики по всем CTA-кнопкам на странице
