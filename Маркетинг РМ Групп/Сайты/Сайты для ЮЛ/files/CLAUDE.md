# Память проекта: Сайты для ЮЛ → публикация на Тильде

Эта папка содержит лендинги юрлиц РМ Групп (`*-landing.html`) и их версии для Тильды (`*-tilda.html`).

## Главное правило

**Исходный лендинг (`*-landing.html`) НЕЛЬЗЯ вставлять в Тильду напрямую.** Это полноценный HTML-документ, а Тильда принимает только фрагмент кода. Перед публикацией любой лендинг обязательно конвертируется.

## Как конвертировать (одна команда)

```bash
python3 tilda_convert.py <имя>-landing.html
```

Результат: `<имя>-tilda.html` рядом с исходником — готов к вставке в Тильду.

При создании НОВОГО лендинга: сначала собрать обычный `*-landing.html` по стандартам папки, затем прогнать через конвертер. Пользователю отдавать ТОЛЬКО `*-tilda.html`.

## Что делает конвертер (и что обязан делать любой код для Тильды)

| # | Правило | Зачем |
|---|---------|-------|
| 1 | Без `<!DOCTYPE>`, `<html>`, `<head>`, `<body>` | Тильда принимает только фрагмент |
| 2 | Все стили изолированы в уникальный контейнер `.<имя>-root` | Стили Тильды и лендинга не конфликтуют |
| 3 | `!important` на color / background / font-family / border-color | Тильда оборачивает страницу в `#allrecords` и красит ссылки своим цветом (оранжевым) — ID-селектор перебивает обычные классы |
| 4 | Меню: `position: fixed` → `position: sticky` | Fixed перекрывает элементы Тильды |
| 5 | Полноэкранные fixed-фоны → `position: absolute` внутри контейнера | Иначе фон вылезает за пределы блока |
| 6 | Тёмный фон принудительно на `html, body` (CSS + JS-дубль) | Убирает белые полосы вокруг блока |
| 7 | Reveal-анимации скрывают контент только при работающем JS (`.js-anim`) + таймер-страховка 2.5с | Если Тильда не выполнит скрипт — контент всё равно виден |
| 8 | Имя сайта в форме заявок прописано жёстко (не из `document.title`) | Внутри Тильды title другой — в Google Таблицу писалось бы не то |
| 9 | Код минифицирован | Длинный код обрезается при вставке в блок T123 → «пустая страница» |
| 10 | `!important` НЕ добавлять внутри `@keyframes` | Ломает анимации |

## РЕКОМЕНДУЕМЫЙ способ публикации: код-загрузчик

Практика показала: даже минифицированный код (~40 тыс. знаков) Тильда обрезает при вставке — на опубликованной странице остаётся только шапка. Поэтому основной способ — **загрузчик**:

1. Готовый `*-tilda.html` кладётся в папку `tilda/` в корне репозитория `DariaClaude/mybestlive` под коротким ASCII-именем (например, `tilda/fabrika.html`) и пушится в GitHub.
2. В блок T123 вставляется только маленький загрузчик (~1 тыс. знаков, файлы `loader-*.html`) — он подтягивает лендинг через CDN jsDelivr и выполняет его скрипты.
3. URL в загрузчике: `https://cdn.jsdelivr.net/gh/DariaClaude/mybestlive@main/tilda/<имя>.html`

Обновление сайта = commit + push нового файла в `tilda/`. Код в Тильде менять не нужно.
**Нюанс:** jsDelivr кэширует ветку main до 12 часов. Чтобы увидеть обновление сразу, открыть в браузере `https://purge.jsdelivr.net/gh/DariaClaude/mybestlive@main/tilda/<имя>.html` — кэш сбросится.

Прямая вставка полного кода (чек-лист ниже) — только для коротких страниц (< 20 тыс. знаков).

## Чек-лист вставки в Тильду (для пользователя)

1. Блок: «+ Добавить блок» → **Другое → T123 «HTML-код»** → «Контент».
2. Вставить код **целиком**, отступы блока сверху/снизу = 0.
3. **Проверить хвост**: последняя строка вставленного кода — `</div>`. Нет — код обрезался, вставить заново.
4. Стандартные шапку/подвал Тильды со страницы удалить (у лендингов свои).
5. Опубликовать → открыть с очисткой кэша (Cmd+Shift+R) → проверить с телефона.

## Типовые симптомы и причины

| Симптом на опубликованной странице | Причина |
|---|---|
| Белый фон, нечитаемый белый текст | Стили не изолированы / без `!important` — перебила Тильда |
| Оранжевые ссылки и кнопки | Цвет ссылок Тильды через `#allrecords` — нужен `!important` |
| Шапка есть, дальше пусто | Код обрезался при вставке (лимит блока) — минифицировать, проверить хвост |
| Контент невидим, но при выделении есть | Reveal-анимации без страховки — скрипт не выполнился |

## Форма заявок

Все лендинги используют общий Google Apps Script (URL внутри кода, менять синхронно во всех файлах). Заявки падают в Google Таблицу с колонкой «site» — она заполняется из жёстко прописанного `siteName`.

## Стандарты новых лендингов

Дизайн: тёмная тема, минимализм, bento-сетки, адаптив на брейкпоинтах 1024 / 640–680 / 480 px. Референсы стиля — `orion-landing.html` и `fabrika-resheniy-landing.html`. ТЗ и брендбуки — в соседней папке `Брендбуки ТЗ`.
