## Шаг 3 — Структура скрипта Apps Script

**Файл-шаблон:** `/Users/daria/Desktop/Сlaude Code/LUIS+/may2026_template.gs`  
*(создаётся в следующем разделе)*

### Функции скрипта:
```
run()     — точка входа: открывает таблицу, удаляет старые вкладки если есть, создаёт новые, вызывает main() и raz()
lnk()     — вспомогательная: создаёт кликабельную гиперссылку через RichText API (не HYPERLINK-формула!)
main()    — заполняет сводную вкладку «Месяц ГГГГ»
raz()     — заполняет вкладку «Раскладка месяц ГГГГ»
```

### Структура вкладки «Месяц ГГГГ» (12 колонок):
| № | Конкурент | Telegram | Постов TG | ВКонтакте | Постов VK | YouTube | Видео | Другие | Всего | Уровень | Ключевые темы |

### Структура вкладки «Раскладка» (8 колонок):
| # | Конкурент | Дата | Платформа | Пост / Контент | Тематика | Охват (просм.) | Ссылка |

**Сортировка раскладки:** по убыванию просмотров. Посты без охвата — в конце.

### Цветовая логика охвата:
- `#e6f4ea` — ≥ 2 000 просм. (Высокий)
- `#fef9e7` — ≥ 1 500 просм. (Хороший)
- `#e8f0fe` — ≥ 500 просм. (Средний)
- `#f8f0ff` — < 500 просм. (Низкий)
- `#ffffff` — нет данных

### Цветовая логика уровня активности:
- `#e6f4ea` — Высокий
- `#fef9e7` — Средний
- `#fce8ff` — Низкий
- `#f1f3f4` — Нет данных

## Шаг 4 — Запуск скрипта

1. Открыть https://script.google.com
2. Проект уже существует (или создать новый)
3. Вставить новый скрипт целиком (Cmd+A → Delete → Paste)
4. Убедиться что в выпадающем списке выбрана функция `run`
5. Нажать **Выполнить** → при первом запуске дать разрешения

**Время выполнения:** ~15–30 секунд  
**Результат:** в журнале появится `Готово`

---

## Шаг 5 — Что обновлять каждый месяц

В скрипте менять:
1. **Названия вкладок** в `run()`: `'Май 2026'` → `'Июнь 2026'` и т.д.
2. **Массив D** в `main()` — данные по конкурентам (посты, уровень, темы)
3. **Массив P** в `raz()` — все посты с датами, охватом, тематикой
4. **Рейтинг** в конце `main()` — топ-5 по активности

## Важные технические замечания

- **Гиперссылки:** всегда через `SpreadsheetApp.newRichTextValue().setLinkUrl()` — HYPERLINK()-формулы дают ошибку в русской локали таблицы
- **Browser.msgBox()** — не работает в standalone скриптах, использовать `Logger.log()`
- **VK.com** — недоступен через WebFetch, использовать WebSearch
- **t.me/s/trassir** — канал закрытый, данные брать с dssl.ru и поиском по СМИ
