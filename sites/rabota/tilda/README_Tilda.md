# Как перенести лендинги в Tilda

Файлы в этой папке — готовые фрагменты для блока **T123 «HTML-код»** (категория «Другое»).

1. Создайте страницу в Tilda → добавьте блок **T123** → «Контент» → вставьте содержимое файла целиком → «Сохранить».
2. В настройках блока T123 уберите отступы сверху и снизу (Padding 0), чтобы шапка лендинга прилегала к краю.
3. Другие блоки Tilda на страницу не добавляйте: лендинг самодостаточный (шапка, форма, футер, липкая кнопка внутри).
4. Счётчик Метрики (99547216) подключите в **Настройки сайта → Аналитика**. Внутри кода счётчика нет, чтобы не задвоить учёт; цели `vacancy_lead`, `form_open`, `phone_click`, `max_click` продолжат отправляться.
5. Логотипы и картинки грузятся по абсолютным ссылкам с dariaclaude.github.io — сайт работает сразу. При желании загрузите их в Tilda и замените пути.
6. Отправка заявки в Google Таблицу: в файле есть строка `var ENDPOINT = "";` — вставьте туда URL веб-приложения Apps Script после его деплоя. Пока пусто, форма показывает «Заявка принята», но никуда не отправляет.
7. Ссылка кнопки «Написать в MAX» сейчас ведёт на max.ru — замените на ссылку аккаунта РМ Групп (поиск по `https://max.ru` в файле, 3 места).
