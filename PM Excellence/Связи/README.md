# Нити — карта деловых связей

Готовое веб-приложение (один файл `index.html`, без сборки и без сервера).
Работает на ПК, планшетах и телефонах. Данные хранятся в браузере пользователя (localStorage), есть экспорт/импорт в JSON.

## Как задеплоить на Vercel (2 минуты, без командной строки)

1. Зайдите на https://vercel.com и войдите (можно через Google/GitHub).
2. Откройте https://vercel.com/new
3. Перетащите **папку** с этим проектом (папку `svyazi`, внутри которой лежит `index.html`) прямо в окно браузера — в зону «Deploy without Git».
   Если зоны drag-and-drop нет: нажмите «Browse» / «Import» и выберите папку.
4. Нажмите **Deploy**. Через ~20 секунд получите публичную ссылку вида `https://niti-xxxx.vercel.app` — её можно открывать с любого устройства.

## Альтернатива: через командную строку

```bash
npm i -g vercel
cd svyazi
vercel --prod
```

## Что умеет

- **Граф** — интерактивная карта связей: перетаскивание узлов, масштаб (колесо/щипок), тап по узлу — карточка человека.
- **Найти выход** — строит самую «тёплую» цепочку от вашей команды к нужному человеку (алгоритм Дейкстры, вес = сила связи × свежесть контакта). Маршрут подсвечивается золотой нитью на графе.
- **Люди** — база контактов: свои сотрудники (отметка «наш человек») и внешние.
- **Связи** — рёбра графа: тип (личное знакомство, работали вместе, эфир, сделка CRM, публикация), сила 1–5, дата последнего контакта.
- **Экспорт/Импорт** — данные скачиваются одним JSON-файлом (резервная копия, перенос между устройствами и коллегами).

## Важно про данные

Сейчас данные хранятся локально в браузере каждого пользователя — это удобно для пилота и не требует бэкенда. Для командной работы с общей базой следующим шагом добавляется база данных (например, Vercel + Supabase/Postgres) и авторизация.
